# 뮤트 버튼 공통 단축키

## 위치와 동작

- 장치 및 실행 탭의 실행 옵션 아래에 한 줄로 배치한다.
- 기본값은 사용 안 함 / F8이다. 키 지정을 눌러 Ctrl, Alt, Shift, Win 조합과 출력 키를 설정한다.
- 게임별 선택이나 프리셋 연결 없이 모든 프로그램에 같은 설정을 사용한다. 입력은 Windows의 현재 활성 창으로 전달된다.
- DS5Light 자체 창 및 키 지정 창에는 입력하지 않는다. DS5Light가 실행 중이면 오디오 엔진의 시작/정지와 독립적으로 작동한다.
- 버튼을 누르는 순간 한 번만 실행한다. Windows 키는 약 30ms 누른 뒤 놓으며, 뮤트 버튼을 계속 눌러도 반복하지 않는다.
- Ctrl, Alt, Shift, Win 또는 출력 키를 키보드에서 이미 누르고 있으면 해당 입력은 생략한다.
- 설정은 실행 파일 옆 preferences.json의 mute_shortcut 항목에 저장한다. 공통 기능 설정으로서 마지막 오디오 설정 복원 스위치와 독립적으로 보존한다. 기존 설정 파일에 항목이 없으면 기본값을 적용한다.

## 구현 범위

- 기존 hidapi로 Sony USB 게임패드 컬렉션의 64바이트 0x01 입력 보고서를 읽는다.
- Studio가 전달하는 뮤트 버튼 비트는 보고서 ID를 포함한 바이트 10의 0x04이다.
- Studio가 마지막 입력을 반복 전송하는 경우를 구분하기 위해 센서 타임스탬프도 확인한다. 0.5초 이상 갱신이 없으면 입력 연결 대기로 전환한다. 새 연결의 첫 상태는 기준값으로만 사용한다.
- 후보 장치가 여러 개면 임의 선택하지 않고 장치 여러 개 상태를 표시한다. 블루투스 직결 보고서 0x31은 처리하지 않는다.
- Windows SendInput은 ctypes로 호출한다. HID 읽기와 키 출력은 별도 스레드에서 처리하며 오디오 경로에 버퍼나 작업을 추가하지 않는다.
- 사용 안 함 상태에서는 HID 장치를 열거하지 않는다. 연결 대기 중에는 최대 2초 간격으로 다시 찾는다. 연결 중 읽기 제한 100ms는 취소 및 오류 확인을 위한 제한이며 데이터가 있으면 바로 반환된다.
- 대기 키 입력은 최대 4개로 제한하고, 250ms 이상 오래된 요청이나 설정/연결 변경 이전 요청은 무효화한다.
- 앱을 닫을 때 대기 요청을 비우고, 전송을 시도한 키는 finally 경로에서 해제한다.
- 장치 쓰기, 펌웨어 변경, 드라이버·패키지 설치, 서비스 및 시작 프로그램 등록을 추가하지 않는다.

## 제한

- 일반 권한 앱은 더 높은 권한의 창에 키를 주입할 수 없다. 자동 권한 상승은 하지 않는다.
- 일부 게임과 입력 필터는 합성 입력을 무시한다. 입력 전달됨 표시는 Windows API가 이벤트를 수락했다는 뜻이며 게임 내부 동작을 보장하지 않는다.
- HID 독점 접근, HidHide, Studio의 뮤트 입력 숨김 매크로가 감지를 방해할 수 있다.
- 원래 뮤트 버튼 기능은 차단하지 않는다. Steam 등에 같은 버튼 매핑이 있으면 이중 동작할 수 있다.
- Ctrl + Alt + Delete는 지원하지 않는다.
- 수신 및 전송 스레드의 스케줄링 비용은 추가된다. 실제 하드웨어 작동, CPU 사용량 및 지연은 아직 측정하지 않았다.
- 이번 작업은 소스 수정이며 실행 시험과 빌드는 수행하지 않았다.
