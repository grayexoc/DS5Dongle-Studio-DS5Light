# DS5Light

## 한국어

ZIP 전체를 쓰기 가능한 폴더에 풀고 `DS5Light.exe`를 실행하세요. Windows 10/11 x64용이며 `_internal` 폴더를 실행 파일 옆에 둡니다. DualSense에 연결된 Studio 동글을 사용하세요.

- 메인 화면에서 장치 전체 또는 선택한 게임의 오디오를 캡처합니다. 게임 캡처는 Windows 빌드 20348 이상에서 지원됩니다.
- `Studio Presert`에는 앱의 추천 메뉴에서 사용하는 Studio 프로필 3개가 있습니다. 저장 후 사용을 선택하면 지정한 동글 슬롯을 덮어씁니다.
- `default_config.json`은 앱 기본 설정입니다. 앱에서 저장한 옵션은 실행 파일 옆 `preferences.json`에 기록됩니다.
- 배포 조건, 출처 및 제3자 고지는 [LICENSES](LICENSES/)에 있습니다.

자세한 설정 방법과 변경 이력은 [프로젝트 문서](https://github.com/grayexoc/DS5Dongle-Studio-DS5Light)에서 확인할 수 있습니다.

## English

Extract the entire ZIP to a writable folder and run `DS5Light.exe`. Use Windows 10/11 x64 and keep `_internal` beside the executable. Connect your DualSense to a Studio dongle.

- Choose whole-device or selected-game capture on the main screen. Selected-game capture requires Windows build 20348 or later.
- `Studio Presert` holds the three profiles used by the app’s recommended presets menu. Save and use overwrites the selected dongle slot.
- `default_config.json` holds the app defaults. Saved options go in `preferences.json` beside the executable.
- Distribution terms, attribution and third-party notices are in [LICENSES](LICENSES/).

See the [project documentation](https://github.com/grayexoc/DS5Dongle-Studio-DS5Light) for setup details and release history.
