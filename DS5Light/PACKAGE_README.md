# DS5Light v1.1.1

Use this Windows x64 package with Studio v50 for Raspberry Pi Pico 2 W.

Extract the entire ZIP to a writable folder and run DS5Light.exe, keeping _internal beside it. No separate Python installation is required.

Choose whole-device or selected-game capture in Audio haptics. Selected-game capture requires Windows build 20348 or later. Studio settings also exposes touchpad mouse operation, speed, small-motion rejection, inversion and trackball settings.

The supplied Mix and Replace presets have changed. We recommend reviewing and applying one as a starting point with the app filter enabled and strength at 100%, then adjusting it to your game and preference. Existing saved slots retain their settings. Stop dongle audio and back up the destination slot before Save and use: it overwrites that slot with the current configuration plus the preset's audio-haptics settings.

Studio Presert contains DS_Native.json, Audio_Haptic_01.json and Audio_Haptic_02.json. default_config.json contains app defaults. Saved preferences are created beside the executable. Licenses and component notices are in LICENSES.

## 한국어

Windows x64용 DS5Light v1.1.1은 Raspberry Pi Pico 2 W용 Studio v50와 함께 사용합니다.

ZIP 전체를 쓰기 가능한 폴더에 풀고 DS5Light.exe를 실행하세요. _internal 폴더를 함께 유지해야 하며 Python을 별도로 설치할 필요는 없습니다.

오디오 햅틱에서 장치 전체 또는 선택한 게임의 캡처를 지정하세요. 게임별 캡처에는 Windows 빌드 20348 이상이 필요합니다. Studio 설정에는 터치패드 마우스 사용, 이동 속도, 미세 움직임 차단, 방향 반전 및 트랙볼 설정이 포함됩니다.

동봉 Mix·Replace 프리셋이 변경되었습니다. 앱 필터 켬·세기 100%를 시작점으로 프리셋을 확인하고 적용해 보는 것을 권장합니다. 이후 게임과 취향에 맞게 조절하세요. 기존 저장 슬롯에는 이전 설정이 유지됩니다. 저장 전 동글 오디오 전송을 멈추고 대상 슬롯을 백업하세요. 저장 후 사용은 현재 구성에 프리셋의 오디오 햅틱 설정을 반영한 결과로 해당 슬롯을 덮어씁니다.

Studio Presert 폴더에는 DS_Native.json, Audio_Haptic_01.json, Audio_Haptic_02.json이 있습니다. default_config.json은 앱 기본 설정입니다. 사용자 설정은 실행 파일 옆에 생성됩니다. 라이선스와 제3자 고지는 LICENSES 폴더에 있습니다.
