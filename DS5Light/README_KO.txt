실행
ZIP 전체를 폴더에 풀고 DS5Light.exe를 실행하세요. _internal 폴더를 함께 유지해야 합니다.
동글은 DS5Dongle Studio 펌웨어와 연결된 DualSense를 사용합니다. 이 프로그램은 펌웨어를 자동 설치하지 않습니다.

오디오 햅틱
저장된 설정이 없는 첫 실행은 장치 전체, PC 억제 필터 켬, 프로세스 정렬 오디오 출력이 기본값입니다.
장치 전체 또는 선택한 게임의 오디오 복사본을 처리해 동글로 전달합니다. 일반 스피커/헤드폰의 게임 소리는 변경하지 않습니다.
게임 캡처를 사용하려면 게임을 실행하고 프로세스 목록을 새로고침한 뒤 실제 게임 프로세스를 선택하세요.
목록은 새로고침할 때만 조회하며 최근 실행, CPU 사용률, 오디오 출력 순서로 정렬할 수 있습니다.
채널 구성은 자동 또는 2/5.1/7.1채널을 선택합니다. 자동은 캡처 형식을 기준으로 선택하며 게임 콘텐츠 자체를 분석하는 기능은 아닙니다.
PC 억제 필터는 배경음과 지속음에 대한 반응을 줄이고 충격음을 보존하도록 보조합니다. 음악·대사 완전 분리는 보장하지 않습니다.
필터를 꺼도 채널 합산과 오디오햅틱 세기는 적용됩니다. 오디오햅틱 세기는 0~150%이며 100%가 기준입니다.
선택한 프로세스가 종료되면 자동으로 정지합니다.

설정과 프로필
마지막 옵션 및 창 크기는 실행 파일 옆 preferences.json에 저장됩니다. 해당 폴더에 쓰기 권한이 있어야 합니다.
preferences.json은 앱 실행 후 생성됩니다. 과거 AppData 설정을 자동으로 가져오지 않습니다.
게임 프리셋은 LocalAppData/DS5Light/presets.json, 언어 설정은 LocalAppData/DS5Light/ui.json에 저장됩니다.
Studio 슬롯 목록은 동글에 저장된 프로필을 조회합니다. 불러오면 오디오 외에 트리거·자이로 등 해당 슬롯 전체 설정도 적용될 수 있습니다.
선택된 저장 프로필이 없으면 불러오기 버튼으로 프로필을 다시 조회할 수 있습니다.
Studio설정 → 추천 프리셋에서 프리셋과 저장 슬롯을 선택하고 저장 후 사용을 누릅니다.
Studio Presert 폴더에는 DS_Native.json, Audio_Haptic_01.json, Audio_Haptic_02.json이 있습니다.
현재 구성의 오디오햅틱 항목만 바꾸고 현재 트리거·자이로·매크로는 유지합니다. 이 현재 구성이 대상 슬롯의 다른 설정까지 대체하므로 덮어쓰기 전에 확인하세요.

마이크 버튼 키보드매핑
설정 및 진단 탭에서 사용을 켜고 키 지정을 선택하세요. 기본값은 사용 안 함 / F8입니다.
게임별 자동 선택 없이 공통 키 조합을 사용하며, 오디오 엔진을 정지해도 DS5Light가 실행 중이면 사용할 수 있습니다.
버튼을 누를 때 한 번 입력하고, 길게 눌러도 반복하지 않습니다. DS5Light 자체 창이나 키보드에서 관련 키를 누르는 중에는 입력을 생략합니다.
관리자 권한 창, 합성 입력을 차단하는 게임, HID 독점/숨김 환경에서는 동작하지 않을 수 있습니다. 원래 마이크 버튼 동작은 차단하지 않습니다.

진단
설정 및 진단 탭에서 처리 상태와 PC 내부 지연을 볼 수 있습니다. USB·블루투스 이후 실제 컨트롤러 진동 지연은 포함하지 않습니다.
장치 전체 지연은 수신 큐 길이 기반 추정값입니다. 정확한 하드웨어 시각이나 손실 횟수의 계측값이 아닙니다.
프로세스 캡쳐는 240프레임(5ms), 장치 전체는 480프레임(10ms) 전송 블록을 사용합니다.
작은 호스트 버퍼를 거부하는 드라이버는 같은 장치에서 480프레임 호스트 버퍼로 다시 엽니다.
정상 전송 중 연결 감지용 주기 조회는 하지 않습니다. 오류·대기·전송 정체 때 조회하고 연속 미검출로 확인합니다.
시작 전 현재 프로필의 오토햅틱 상태는 항상 다시 확인합니다. 최근 슬롯 목록은 재사용하며 명시적 조회는 새로 읽습니다.
선택한 게임 캡처는 Windows 빌드 20348 이상에서 지원됩니다. 이전 Windows 10 빌드에서는 장치 전체 캡처를 사용하세요.
실제 게임 호환성, 진동 체감 및 하드웨어 지연은 사용 환경에 따라 다릅니다.
