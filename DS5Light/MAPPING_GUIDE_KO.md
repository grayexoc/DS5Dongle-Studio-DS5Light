# Pico 시프트·프로필 전환 매핑 — DS5Light v1.0.6 / Studio v34

- Studio 설정 → 매핑·매크로 → 시프트키 지정에서 아이콘·버튼명 선택판을 펼쳐 지정합니다.
- Fn·백버튼은 첨부 이미지 기반 SVG로 선택판에 표시합니다. 별도 그림 창은 없습니다.
- 기본/시프트 탭에서 매핑을 추가합니다. 시프트키를 누르는 동안만 시프트 매핑을 사용하고, 지정하지 않은 입력은 기본 매핑을 상속합니다.
- 시프트키 자체는 게임으로 전달하지 않습니다. 기존 동작이 지정된 버튼을 시프트키로 쓰면 그 버튼의 기존 매핑보다 시프트가 우선합니다.
- 시프트키는 Pico 공통 매크로 한 칸을 사용하며, 현재 프로필에서 사용 체크는 프로필별입니다. 총 32칸 한도는 유지됩니다.
- 실행 동작 → 출력 종류 → 프로필 전환에서 프로필 1~8번을 고릅니다. 목록명 조회는 추가하지 않았습니다.
- 빈 슬롯은 전환하지 않습니다. 같은 슬롯 재선택은 무시합니다. 누르고 있어도 반복 전환하지 않습니다.
- 전환 신호음은 기본 꺼짐입니다. 켜면 해당 매크로가 실제로 다른 프로필을 불러온 후에만 짧은 소리를 냅니다. 미리듣기는 프로필을 바꾸지 않습니다.
- 신호음은 기존 스피커 전송 경로로 합성하며 네이티브·오디오햅틱의 입력에는 섞지 않습니다. 프로필의 스피커 음량이 0이면 들리지 않을 수 있습니다. 헤드셋이 연결돼 있으면 헤드셋 경로를 따릅니다.

## 저장 순서

1. 매핑 편집 또는 시프트키 지정에서 **편집에 반영**.
2. **Pico 매핑·매크로 저장**으로 공통 동작 저장.
3. **현재 프로필에 저장**으로 해당 프로필의 사용 체크 저장.

확장 동작 저장에는 시프트·프로필 전환 기능을 지원하는 펌웨어가 필요합니다. 이번 릴리즈에는 v34를 동봉합니다. 구형 펌웨어에서는 확장 동작의 쓰기를 차단합니다. 기존 동작은 기존 명령을 그대로 사용합니다.

## 확인이 남은 항목

- 실제 컨트롤러에서 시프트 해제·프로필 전환·USB 모드가 다른 프로필 간 재연결.
- 스피커 신호음의 음량·팝핑·헤드셋 경로와 실행 중 게임 오디오와의 동시 재생.
- Edge 자체 Fn+도형 버튼 조합은 컨트롤러 내장 프로필 기능과 겹칠 수 있습니다. 기본 동작을 존중하기 위해 FN+얼굴 버튼·방향키·Options 조합은 매핑 활성화를 제한합니다.

펌웨어를 낮은 버전으로 되돌리기 전에는 시프트·프로필 전환 레코드를 제거하거나 사용 체크를 해제하세요. 구형 펌웨어는 새 플래그의 의미를 모릅니다. 프로필·매크로 백업 후 설정하는 것을 권장합니다. 이 빌드는 장치에 자동 기록하지 않습니다.


## 스와이프 클릭 차단

스와이프는 방향 감지로 한 번 실행되므로 누르는 방식 설정은 표시하지 않습니다. 대신 ‘터치패드 클릭을 게임에 전달하지 않기’를 선택할 수 있습니다. 현재 프로필·레이어에서 해당 매핑이 활성인 동안 클릭만 차단하고 터치 위치·이동·스와이프는 유지합니다. 클릭 기능을 다시 쓰려면 활성 스와이프 행의 차단 옵션을 모두 해제하세요. 이 옵션은 동봉 v34 또는 해당 기능을 지원하는 펌웨어가 필요합니다.

장치 진단에서 오디오 출력을 찾지 못하면 ‘오디오 출력 연결’에서 해당 Pico의 4채널 출력을 선택하세요. 연결 확인 자체로 시험음은 재생하지 않습니다.
