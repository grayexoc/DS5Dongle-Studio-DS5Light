DS5Light 통합 앱용 추천 프리셋

파일: DS_Native.json, Audio_Haptic_01.json, Audio_Haptic_02.json.
Studio 설정 → 프로필 슬롯 → 추천 프리셋에서 프리셋과 저장 슬롯을 선택한 뒤 저장 후 사용을 누릅니다. 저장 전 동글 오디오 전송을 정지하세요.

현재 구성의 허용된 오디오햅틱 항목만 바꿉니다. 다른 현재 설정과 매크로를 유지한 결과를 선택한 슬롯에 저장합니다. 슬롯을 덮어쓰면 대상 슬롯의 다른 설정도 현재 구성으로 대체되며 대상 슬롯의 기존 구성을 보존하는 방식이 아닙니다.

DS Native는 오디오햅틱을 끕니다. 네이티브 햅틱으로 전환할 때 PC 오디오 처리도 정지하세요. 오디오햅틱 믹스는 Front 오디오와 Rear의 네이티브 햅틱 원본을 함께 사용합니다. 오디오햅틱 대체는 Front 오디오만으로 진동을 만듭니다. 두 프리셋 모두 앱 필터를 켜고 배경 억제량 55%·앱 오디오햅틱 세기를 1x(100%)로 두는 설정입니다.
