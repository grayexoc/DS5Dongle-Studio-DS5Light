# Modified 빌드 추가 기능

- PC 필터의 배경 억제량과 타격 보존량을 독립 조절합니다. 타격 보존 기본값은 85%입니다. 기존 진동 세기 0~150%와 별개입니다.
- 과거 신호만 사용하는 빠른/느린 에너지 검출기를 분리하고 저역 평균을 안정화했습니다. 짧은 타격 보호 및 제한된 배경 학습 정지를 적용하며, 반복 신호가 배경 학습을 영구 정지시키지 않게 합니다. 디지털 무음 바닥값과 입력 음량에 비례하는 문턱을 사용합니다. 별도의 오디오 대기 버퍼나 GPU 모델은 추가하지 않습니다.
- 필터 시작 시 요청한 감쇠에서 출발합니다. 정지·재시작 및 우회 후 필터 재진입 시 처리기를 초기화합니다. 완전한 배경음/대사/효과음 분리기는 아니므로 음악의 타악기도 보호될 수 있습니다.
- 채널 선택의 기본값은 자동입니다. 시작할 때만 게임의 읽을 수 있는 활성 오디오 세션 채널 수를 참고합니다. 확인 불가이면 8→6→2채널 순서로 명시적인 형식 미지원 오류에만 대체 형식을 시도합니다. 접근 거부·게임 종료·시간 초과는 자동 전환 사유가 아닙니다. 게임 전용에서 장치 전체로는 전환하지 않습니다.
- 자동의 캡처 형식은 게임의 원래 출력 형식을 확정한 표시가 아닙니다. 조용한 채널을 보고 재생 중 형식을 변경하지 않습니다. 일반 스테레오로 이미 합쳐진 신호의 센터·후방·LFE는 복원할 수 없습니다.
- 표준 5.1 및 7.1-surround 캡처의 센터·LFE·후방/측면을 기존 선택에 따라 합산합니다. 장치 전체 캡처의 8채널 합산은 확인한 채널 마스크가 표준 7.1-surround일 때만 적용합니다. 수동 2/5.1/7.1 선택도 유지합니다.
- 장치 및 실행 탭의 Studio 프로필은 사용자 제공 DS5Light-OG의 슬롯 통신을 이식했습니다. 조회 버튼으로 동글 후보와 저장 슬롯 1~10, 지원 시 현재 슬롯을 읽습니다. 여러 후보가 있으면 임의로 선택하지 않습니다. 슬롯 선택만으로 적용하지 않으며, 오디오 정지 상태에서 불러오기를 눌러 적용합니다. 슬롯 전체 설정에 트리거·자이로 등이 포함됩니다. 빈 슬롯·사용 불가 슬롯은 적용하지 않습니다.
- Studio 조회와 적용은 별도 작업 스레드에서 수행하고 유휴 HID 폴링은 하지 않습니다. 응답을 잃은 적용 명령은 재전송하지 않습니다. USB 설정 변경으로 재연결이 필요한 경우 표시합니다. 슬롯 저장/덮어쓰기·강도/트리거 값 수정·자동 슬롯 적용은 이식 범위에 포함하지 않습니다.
- 세부 설정 버튼을 제거하고 둥근 금색 체크와 타격 보존 슬라이더를 직접 배치했습니다. 장치/실행 옵션, Studio 슬롯, 진단을 동일한 카드 여백으로 배치했습니다. 제목, 검정/골드 테마, 고정 하단 영역 및 창 크기 저장을 유지합니다.
- 프리셋은 버전 6이며 기존 버전 1~5는 첫 변경 저장 전에 백업합니다. 마지막 옵션과 창 크기는 실행 파일 폴더의 preferences.json에 저장합니다. 기존 게임별 자동 연결과 출력 장치 고정 재연결 기능을 유지합니다.

검증 범위: 소스 자동 검증, 합성 신호 회귀 비교, 최소/기본 창 크기 배치, 실제 Windows 2/6/8채널 캡처 초기화와 패키지 초기화 확인. 실제 게임의 소리 종류 분리 정확도와 컨트롤러 진동, 실제 Studio 동글 슬롯 적용/재연결은 하드웨어 검증이 별도로 필요합니다.

## 컴팩트 UI 업데이트

- 상단 브랜드 글자 확대와 조작부의 수직 중심 정렬, 하단 상태/연결 글자 확대를 적용했습니다. 탭 오른쪽으로 이어지던 캔버스 선을 제거했습니다.
- 세부 채널과 토글/합산 제한은 명시적으로 5.1 또는 7.1을 선택할 때만 표시합니다. 자동의 저장된 채널 기여 옵션은 유지합니다.
- Studio 프로필은 오디오 햅틱 탭에 프로필 슬롯/불러오기 한 줄로 이동했습니다. 별도의 동글 선택/조회 및 설명 문구를 제거했습니다. 일반 수동 시작 상태에서는 최초 1회 자동 조회하며 프로필 목록을 열 때 갱신합니다. 자동 시작이 켜진 경우 최초 조회로 시작을 지연시키지 않습니다. 여러 동글은 목록의 장치 구분과 각 슬롯의 실제 HID 경로를 함께 보존합니다. 슬롯 적용은 사용자가 불러오기를 누를 때만 수행합니다.
- 실행 옵션은 한 줄의 내용 높이에 맞추고, 장치 입력/출력을 나란히 정렬했습니다. 오디오 처리 알고리즘과 전송 버퍼는 이번 UI 변경으로 수정하지 않았습니다.
