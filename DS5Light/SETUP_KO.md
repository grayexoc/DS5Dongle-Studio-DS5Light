# DS5Light 시작 안내

[English](SETUP.md) · [프로그램 사용법](README_KO.txt) · [버전 및 릴리즈 안내](RELEASE_NOTES.md)

## 패키지와 펌웨어

Windows 10/11 x64에서 `DS5Light-win-x64-v1.0.4.zip` 전체를 쓰기 가능한 폴더에 풀고 `DS5Light.exe`를 실행하세요. 실행 파일 옆의 `_internal` 폴더를 함께 유지해야 합니다. 실행 배포본에는 Python 설치가 필요하지 않습니다.

통합 릴리즈는 v1.0.4, 앱은 v1.0.4, 펌웨어는 Studio v32입니다. 펌웨어는 별도 첨부 파일 `ds5-studio-light_v32.uf2`로 제공합니다. 이 파일은 Raspberry Pi Pico 2 W용이며 RP2040 Pico W나 Waveshare 보드용이 아닙니다. 앱이 펌웨어를 자동으로 설치하지는 않습니다.

펌웨어 변경이나 프로필 저장 전에 현재 설정과 슬롯을 백업하세요. 이 포크의 추가 설정·진단에는 해당 펌웨어의 지원이 필요합니다. 기존 호환 Studio에서도 기본 오디오 전송이 가능할 수 있지만 추가 기능이 모두 제공되는 것은 아닙니다. 일반 설치에 flash_nuke 초기화는 필요하지 않습니다.

## 앱에서 Studio 준비

1. 동글과 컨트롤러를 연결합니다. 설정 저장 전 DS5Light의 오디오 처리를 정지하고, 동글에 오디오를 보내는 다른 프로그램도 정지하세요.
2. **Studio설정** 탭을 엽니다. 진입하면 현재 설정을 읽으며, 장치나 프로필이 바뀌었다면 **새로 고침**으로 확인하세요. 장치가 여러 개라면 대상 장치를 선택합니다.
3. **추천 프리셋**에서 아래 세 가지 중 하나를 선택합니다. 실행 파일 옆 `Studio Presert` 폴더의 파일을 사용합니다.

| 파일 | 앱의 프리셋 | 용도 |
| --- | --- | --- |
| `Audio_Haptic_01.json` | 오디오햅틱 안정형 | 배경 반응을 줄이는 쪽의 오디오 햅틱 시작점입니다. |
| `Audio_Haptic_02.json` | 오디오햅틱 반응형 | 효과음 반응을 더 살리며 배경음 반응도 더 남을 수 있습니다. |
| `DS_Native.json` | 네이티브 프리셋 | 오디오 햅틱을 끄고 게임의 네이티브 햅틱·일반 진동을 사용합니다. 게임·연결 방식이 지원해야 합니다. |

4. **저장 슬롯**을 고르고 **저장 후 사용**을 누릅니다. 덮어쓰기 안내가 나오면 대상을 확인하세요. 기존 슬롯을 보존하려면 빈 슬롯을 선택합니다.
5. 저장·전환 결과를 기다립니다. 저장 확인이 불확실하거나 재연결이 필요하면 새로 고침으로 현재 프로필을 확인한 뒤 계속하세요. 확인되지 않은 저장을 성공으로 간주하지 마세요.

추천 프리셋은 **현재 설정의 오디오햅틱 항목만** 추천값으로 바꿉니다. 현재 장치·자이로·트리거·매크로 설정은 유지합니다. 그 결과인 현재 구성을 선택한 슬롯에 저장하므로, 슬롯을 덮어쓸 때 대상 슬롯에 들어 있던 다른 설정을 유지하는 방식은 아닙니다. 전체 프로필 가져오기·백업 복원이나 기존 동글 슬롯 불러오기는 적용 범위가 다릅니다.


## 오디오 햅틱 시작

1. 원래 게임 소리는 평소의 스피커·헤드폰으로 출력합니다.
2. **오디오햅틱** 탭에서 장치 전체 또는 선택한 게임 캡처를 고릅니다. 게임 전용이면 게임을 실행하고 목록을 새로고침하여 실제 실행 파일을 선택하세요. 연결 설정에서 출력 동글도 확인합니다.
3. 저장 설정이 없는 첫 실행은 **PC 억제 필터 켬**, **균형**, 억제량 55%, 타격 보존 85%, 세기 100%, 채널 자동이 기본입니다. 기존 저장 설정이 있으면 그 값이 우선하므로 시작 전에 화면을 확인하세요.
4. 처리를 시작하고 억제량·타격 보존량·세기를 각각 조절합니다. 음악·대사·효과음을 완전히 분리하는 기능은 아닙니다.
5. 유용한 설정은 PC 게임 프리셋 12개 중 하나에 저장합니다. PC 프리셋과 동글 프로필 슬롯은 별개이며, PC 설정 저장·불러오기만으로 동글 슬롯을 활성화하지는 않습니다.

자동·스테레오·5.1·7.1 캡처를 지원합니다. 센터·LFE·후방/측면 기여도는 다채널 입력이 필요하며, 이미 스테레오로 합쳐진 채널은 복원할 수 없습니다. 자동 캡처 형식이 게임 내부 오디오 설정을 확정하는 것은 아닙니다. 게임 전용 캡처에는 Windows 빌드 20348 이상이 필요하며, 이전 Windows 10에서는 장치 전체 캡처를 사용하세요.

## 네이티브 햅틱과 문제 확인

- 네이티브 프리셋이나 적절한 기존 네이티브 프로필을 사용하기 전에 오디오 처리를 정지하세요. PC 필터만 끄면 오디오 전송은 계속됩니다.
- 오디오햅틱 탭에서 기존 동글 슬롯을 불러오면 트리거·자이로를 포함한 슬롯 전체 설정이 적용됩니다.
- 진동이 없으면 컨트롤러 연결, 출력 선택, 활성 Studio 프로필과 오디오햅틱 모드, 캡처 신호와 세기를 순서대로 확인하세요.
- 추가 장치 설정·테스트는 펌웨어 지원이 필요합니다. XInput은 실험적 기능이며 DualSense 모드와 차이가 있습니다.
- 진단의 시간 표시는 PC 내부 시간 또는 큐 기반 추정치이며 실제 컨트롤러 출력 지연 측정값이 아닙니다.

설정 저장과 사용법은 [README_KO.txt](README_KO.txt)를 참고하세요. 원본 프로젝트: [Studio](https://github.com/artzox/DS5Dongle-Studio), [DS5Light](https://github.com/fnflwkd/DS5Light).
